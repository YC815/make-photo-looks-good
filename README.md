# 像素延伸（make-photo-looks-good）

把照片裡的主體抓出來，從任一方向擷取主體最外圍的一排像素，再把這排顏色往外拉長、用鋼筆工具彎折。

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # 幾何與擷取演算法的單元測試
npm run build
```

## 流程

1. **載入照片**：選檔、拖進畫面，或 ⌘V／Ctrl+V 貼上。
2. **抓主體**，三選一：
   - **在畫面上點選主體**：瀏覽器端的 MediaPipe「magic touch」模型，點一下就抓（第一次會下載約 6 MB 模型）。
   - **貼上 Apple「照片」去背結果**：在「照片」長按主體 →「拷貝」→ 貼過來。有透明背景的圖會自動把 alpha 當主體，並外擴畫布讓色帶有地方延伸。
   - **匯入遮罩**：白＝主體的灰階 PNG，或帶透明度的 PNG。Mac 可以用 [`tools/apple-vision-mask`](tools/apple-vision-mask/) 以 Apple Vision 產生，同時保留原背景。
3. **方向與擷取線**：主體外圍會出現最小包圍圓。拖圓上的 ↻ 選方向，該方向會出現一條長度＝直徑、與圓相切的擷取線，能完整蓋住主體。
   - 線上每一點都朝主體看過去，取第一個碰到的主體像素（青色細線標示）。
   - 往內推這條線，擷取的就變成「線後面的部分」；推進主體裡面，就是經典的直線切片。
   - 拖線的兩端可以只擷取其中一段。
   - 「取色內縮」可以避開邊緣反鋸齒的雜色，「色帶平滑」可以壓掉 JPEG 或去背邊緣造成的條紋。
4. **延伸與彎折**：色帶沿著一條 Bézier 路徑延伸，操作方式跟鋼筆工具相同。拖最後一個錨點可以調整長度；用鋼筆點空白處加錨點，按住拖曳可以拉出把手；Option／Alt 可以打斷對稱。路徑綁在擷取線上，改方向時會跟著轉。
5. **輸出**：背景可選原圖、透明或純色；可以讓主體疊在色帶上面；調整畫布外擴後下載 PNG。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/geometry.ts` | 向量、凸包、最小包圍圓（Welzl） |
| `src/mask.ts` | 遮罩、由遮罩求包圍圓 |
| `src/capture.ts` | 擷取線與射線取色、色帶平滑 |
| `src/path.ts` | 鋼筆路徑：三次 Bézier、展平、插入／移動錨點、對稱把手 |
| `src/ribbon.ts` | WebGL2：把色帶當 1px 高的貼圖，沿路徑掃成三角帶 |
| `src/segment.ts` | MediaPipe 點選分割（延遲載入） |
| `src/main.ts` | 介面、互動、合成 |
| `tools/apple-vision-mask/` | macOS 用 Apple Vision 產生遮罩的 Swift 腳本 |
