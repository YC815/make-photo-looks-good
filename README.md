# 像素延伸（make-photo-looks-good）

把照片裡的主體抓出來，從任一方向擷取主體最外圍的一排像素，再把這排顏色往外拉長、用鋼筆工具彎折。

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # 幾何與擷取演算法的單元測試
npm run build
```

## 流程

1. **載入照片**：選檔、拖進畫面，或 ⌘V／Ctrl+V 貼上。
2. **抓主體**，三選一：
   - **在網頁上抓**：按「點選主體」，在主體上點一下，由瀏覽器端的 MediaPipe「magic touch」模型抓出來（第一次會下載約 6 MB 模型）。
   - **貼全圖＋貼主體**：在 Apple「照片」長按主體 →「拷貝」，貼過來（或按「選擇去背主體」）。
     - 已經有原圖：去背主體會自動對位到原圖上，背景保留。
     - 先貼主體、再貼原圖：也會自動對位。
     - 只有主體：單獨使用，畫布會外擴，讓色帶有地方延伸。
     - 對位的做法是在原圖裡搜尋主體的位置和縮放比例，所以就算去背圖和原圖的解析度不同也能對上。
   - **匯入遮罩**：白＝主體的灰階 PNG，或帶透明度的 PNG，尺寸會自動縮放到跟原圖一樣。
3. **修邊**：用「魔法擦除」（E）去掉多抓的部分，「魔法復原」（R）補回漏抓的部分。選取方式有三種：
   - **AI 智慧選取**：點一下，選整個物件。
   - **顏色魔術棒**：點一下，選相近顏色的連續區域，容許度可調。擦除時只會在主體內擴散，復原時只會在背景內擴散，不會越過邊界。
   - **筆刷**：自己塗。
   
   工具列可以切換檢視：「成品」「只看主體」「遮罩」（紅色＝目前被當成背景的部分），按 B 循環切換。所有步驟都可以 ⌘Z／⇧⌘Z 上一步、下一步。
4. **方向與擷取線**：主體外圍會出現最小包圍圓。拖圓上的 ↻ 選方向，該方向會出現一條長度＝直徑、與圓相切的擷取線，能完整蓋住主體。
   - 線上每一點都朝主體看過去，取第一個碰到的主體像素（青色細線標示）。
   - 往內推這條線，擷取的就變成「線後面的部分」；推進主體裡面，就是經典的直線切片。拖線的兩端可以只擷取其中一段。
   - 「取色內縮」可以避開邊緣反鋸齒的雜色，「色帶平滑」可以壓掉 JPEG 或去背邊緣造成的條紋。
   - **主體內部的空隙**（射線碰到主體後，在主體後面又遇到的背景，例如花瓣之間）有三種處理方式：留空、用內側顏色往外延伸（每一層內側表面也各自拉伸），或讓外側顏色貫穿進去。
5. **延伸與彎折**：色帶沿著一條 Bézier 路徑延伸，操作方式跟鋼筆工具相同。拖最後一個錨點可以調整長度；用鋼筆點空白處加錨點，按住拖曳可以拉出把手；Option／Alt 可以打斷對稱。路徑綁在擷取線上，改方向時會跟著轉。
   - **跟著轉彎（不摺疊）**：每個像素取「離路徑最近的那一點」的顏色。做法是把到路徑的距離寫進深度緩衝，路徑兩端再加上只寫深度的距離圓錐，用深度測試求出完整的距離場。急轉彎時內側會乾淨切齊，不會摺疊交錯，也不會繞到擷取線後面。
   - **平移（像扁筆刷）**：截面方向固定、只沿路徑平移，像書法扁筆。
   - **寬度**：設定起點寬度和終點寬度（100%＝擷取線原本的寬度，低於 100% 是收斂，0% 會聚到一點，高於 100% 是擴散）。
     - 過渡方式可選「平滑過渡」「直線過渡（轉角是硬的）」或「直接硬切（在「始」點瞬間改變）」。
     - 過渡的開始和結束位置可以用滑桿調，也可以直接拖路徑上的「始」「終」兩點。
   - **尾端平移**：拖尾端的青色圓點（還沒移動時是錨點外的一圈），色帶會在過渡區間內平移過去，聚攏點因此可以放在任何位置。
   - **尾端淡出**。
6. **輸出**：背景可選原圖、透明或純色；可以讓主體疊在色帶上面；調整畫布外擴後下載 PNG。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/geometry.ts` | 向量、凸包、最小包圍圓（Welzl） |
| `src/mask.ts` | 遮罩、由遮罩求包圍圓 |
| `src/maskEdit.ts` | 魔術棒、筆刷、選取合併 |
| `src/capture.ts` | 擷取線與射線取色、內部空隙、色帶平滑 |
| `src/path.ts` | 鋼筆路徑：三次 Bézier、展平、插入／移動錨點、對稱把手 |
| `src/ribbon.ts` | WebGL2：色帶沿路徑掃成三角帶；距離場彎折、平移、寬度曲線、淡出 |
| `src/segment.ts` | MediaPipe 點選分割（延遲載入） |
| `src/align.ts` | 把去背主體對位回原圖（多尺度樣板比對） |
| `src/main.ts` | 介面、互動、合成 |
